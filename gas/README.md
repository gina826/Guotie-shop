# 結帳系統串接 Google Sheets 部署說明

網站送出訂單 → Google Apps Script（網頁應用程式）→ 寫入你的 Google 試算表。

## 一、建立試算表與腳本（約 5 分鐘）
1. 在 Google 雲端硬碟新增一個空白試算表，命名例如「鍋貼訂單」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原有內容全部刪掉，貼上本資料夾 `Code.gs` 的全部內容，按存檔。
4. 上方函式選單選 **setup**，按「執行」，依畫面授權（第一次會要求授權，選你的帳號 → 進階 → 前往）。
   完成後試算表會自動出現「訂單」「訂單明細」兩個分頁。

## 二、部署成網頁應用程式
1. 右上角 **部署 → 新增部署作業**，類型選 **網頁應用程式**。
2. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（網站訪客不需登入才能下單）
3. 按「部署」，複製 **網頁應用程式網址**（結尾是 `/exec`）。
4. 用瀏覽器直接開這個網址，看到 `{"ok":true,"service":"guotie-orders",...}` 就代表成功。

## 三、接到網站
把網址貼到 `index.html` 裡這一行（搜尋 `ORDER_ENDPOINT`）：

```js
const ORDER_ENDPOINT = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

存檔、推送、合併後，網站下單就會寫入試算表。留空則維持原本的模擬結帳。

## 四、選用：新訂單 Email 通知
Apps Script 左側 **專案設定 → 指令碼屬性 → 新增**：名稱 `OWNER_EMAIL`，值填你的 Email。

## 之後修改腳本要注意
修改 `Code.gs` 後必須 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，
網址不變，但不重新部署的話線上仍是舊程式。

## 試算表欄位
- **訂單**：訂單編號、建立時間、取餐方式、姓名、手機、外送地址、取餐時間、備註、品項摘要、小計、運費、應付總額、狀態（下拉：待處理/製作中/可取餐/已完成/已取消）、客戶端ID
- **訂單明細**：每個品項一列，方便做銷售統計

## 已內建的防護與限制
- 訂單編號由伺服器產生（`GT` + 日期 + 流水號）；同一筆重複送出會回傳原編號，不會重複寫入。
- 金額由伺服器依品項重新加總，並套用宅配運費規則（未滿 600 元加 60 元）。
- 隱藏欄位（honeypot）擋機器人；同一手機 5 秒內不可連續下單；備註等欄位會避免被當成試算表公式。
- **限制**：單價仍由網站傳來，伺服器只檢查合理範圍。若要防止有人竄改價格，下一步可在試算表新增「菜單」分頁，由腳本依品項 ID 查價。
- 此腳本網址是公開的（任何人都能對它送資料），請不要在試算表放敏感資料。
